## Bilan des commandes Git

### 1. `git status`

Permet de vérifier l'état du dépôt, notamment les fichiers modifiés, les fichiers préparés pour un commit et les fichiers non suivis.

### 2. `git remote -v`

Permet d'afficher les dépôts distants configurés ainsi que leurs URL pour les opérations de récupération et de publication.

### 3. `git log --oneline --graph --all`

Permet de consulter l'historique des commits sous forme graphique et de visualiser les branches ainsi que les opérations de fusion.
